# ECD Eventos

Planejamento completo de **casamentos, 15 anos, aniversários e eventos corporativos**: orçamento, fornecedores e parcelas, convidados com confirmação pelo celular, tarefas, cronograma do dia, ordem da cerimônia com guia para os músicos e playlist montada com sugestões dos convidados.

Feito para noivos, anfitriões e **cerimonialistas que cuidam de vários eventos ao mesmo tempo**.

**Demonstração:** https://du-edu-duarte.github.io/ecd-eventos/

> Versão de demonstração com nomes e valores fictícios. Tudo fica salvo apenas no navegador de quem está usando.

## O que ele faz

- **Vários eventos no mesmo painel**, cada um com cor própria, contagem regressiva, andamento das tarefas, convidados confirmados e quanto já foi pago.
- **Modelos prontos por tipo de evento:** ao criar, as tarefas por fase (12 meses, 6 meses… última semana), o cronograma do dia e a ordem da cerimônia já vêm preenchidos.
- **Orçamento e fornecedores:** valor contratado, parcelas com vencimento, "marcar como pago", aviso de parcela vencida, gasto por categoria, botão de WhatsApp e exportação em Excel.
- **Convidados:** grupos, adultos e crianças, mesa e filtros. Dá para colar a lista inteira do Excel. Pelo **link de confirmação** o convidado procura o nome e responde pelo celular, com recado (ex.: restrição alimentar).
- **Tarefas** com responsável e quem concluiu.
- **Cronograma do dia** em linha do tempo, pronto para imprimir.
- **Cerimônia e músicos:** ordem das entradas com música, link do YouTube e horário, aviso de música repetida, equipe, traje e um **guia público** para os músicos.
- **Playlist da festa:** os convidados sugerem músicas por um link. O sistema junta as repetidas, ordena pelas mais pedidas, permite aprovar ou tirar músicas e exporta a lista para o DJ.
- **Acesso só para clientes**, com o mesmo login com convite dos outros sistemas ECD, e **tema preto e branco**.

## Tecnologias

HTML, CSS e JavaScript puro · IndexedDB · GitHub Pages

## Rodar localmente

```bash
python3 -m http.server 8000
```

## Versão para empresas

Na versão para empresas, os dados ficam num servidor. Assim a confirmação dos convidados e as sugestões de música chegam de qualquer celular direto para o painel, e o sistema pode avisar os vencimentos das parcelas.
